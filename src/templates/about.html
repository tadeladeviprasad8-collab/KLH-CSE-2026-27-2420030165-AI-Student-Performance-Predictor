ℹ️ About GradeMind

🎯 Problem Statement

Educational institutions need data-driven methods to identify students who may be at risk of underperforming, so that timely interventions can be made. Manual evaluation alone is insufficient when dealing with large student populations. GradeMind addresses this by using machine learning to predict student performance based on academic indicators.

💡 Solution

GradeMind is an AI-based web application that predicts whether a student will achieve Pass, Merit, or Distinction based on five key academic features:

  • Attendance Percentage
  • Internal Marks
  • Assignment Score
  • Study Hours Per Week
  • Previous GPA

🤖 Machine Learning Model

The system uses a Random Forest Classifier trained on a synthetic dataset of 1000 student records. The model is evaluated using standard metrics (Accuracy, Precision, Recall, F1-Score) and tracked using MLflow for experiment reproducibility.
