# GDPR and Data Privacy

This document addresses data privacy and GDPR (General Data Protection Regulation) concepts within the context of the GradeMind project.

## Core GDPR Principles
1. **Data Minimization**: Collect only the data necessary for the specific purpose. GradeMind only requests academic features (attendance, marks, study hours), avoiding personal identifiers like names or addresses in the prediction model.
2. **Purpose Limitation**: Data should only be used for the purpose it was collected. In a real scenario, student data collected for administrative purposes shouldn't be used for ML predictions without explicit permission.
3. **Consent**: Users (or their guardians) must explicitly agree to have their data processed by the AI system.
4. **Data Protection and Security**: Data must be stored securely.
5. **Right to Deletion (Right to be Forgotten)**: Individuals can request the removal of their personal data from the system.

## GradeMind Implementation Details
- **Synthetic Data**: To ensure privacy and comply with data protection standards during development, the GradeMind project uses **strictly synthetic (fake) data** generated by `generate_dataset.py`.
- **No Personal Information**: The dataset does not contain real names, real student IDs, contact information, or demographic data.
- **Local Processing**: By default, the ML model training and predictions run locally, meaning no student data is transmitted to external servers without the user's explicit deployment.
